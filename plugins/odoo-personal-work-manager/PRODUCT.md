# Product

<!-- impeccable:product-schema 1 -->

## Platform
ChatGPT MCP Apps dashboard, standalone web setup, Node connector, Odoo 19 addon.

## Stack
Chosen under the user's instruction to implement the complete review: Node 24, official MCP SDK, MCP Apps bridge, plain HTML/CSS/JavaScript and Odoo Python. The production domain and identity provider remain deployment choices.

## Users and purpose
Odoo users managing their own work, and authorized managers assigning tasks or creating projects. They need tasks/projects, logged time, todos and notes in one conversational workspace, including instances with custom modules and no backend dashboard.

## Constraints
Odoo permissions remain authoritative. Custom business meaning requires verified mappings. Secrets must not enter chat. Writes need an exact preview, confirmation and verification. Unknown completion stays unknown. Demo data must be labelled. No live customer instance was supplied for validation.
