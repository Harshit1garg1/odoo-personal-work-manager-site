Support

For questions, bug reports or suggestions about Odoo Personal Work Manager, use the project's GitHub issue tracker.

Open a support issueDeveloper profile

What to include

  • A short description of what you were trying to do.
  • The ChatGPT/plugin version and Odoo version, if relevant.
  • Steps to reproduce the issue, with fictional or anonymized sample data.
  • The exact error message after removing names, URLs, identifiers and other private information.
Do not post secrets or business data.

GitHub issues are public. Never include Odoo API keys, passwords, session cookies, customer information, employee information, internal URLs, database exports, private task descriptions or screenshots containing confidential information.

Current release limitations

The current release contains workflow guidance only. It does not connect directly to an Odoo server or perform live database reads or writes. A future connector will be documented here after it is implemented and its security and support arrangements are established.

Response times

This is an independently maintained project. Support is best-effort; no response-time commitment or service-level agreement is currently offered.
