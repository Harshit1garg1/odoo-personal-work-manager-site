Architecture & Release Status

Current Implementation · v0.2.0

Connector, Dashboard & Workflows

The downloadable developer preview includes authenticated tools, a dashboard, an Odoo addon and workflow instructions. It does not include a public live endpoint.

  • Five Work Areas: Projects, tasks, timesheets, todos and notes through the connector.
  • Secure Connection Setup: API keys go to the deployed connector’s credential form, never ordinary chat.
  • Custom Company Mappings: Use verified fields, required defaults and supported workflow actions.
  • Reviewed Writes: Preview, confirmation, saved-value checks and duplicate-safe operation receipts.
Before Connecting Live Odoo

Deployment & Staging Validation

Odoo 19 is the implementation target. Local checks passed; live Odoo, real-provider OAuth and a ChatGPT-hosted connection still require staging validation.

  • Odoo Deployment: Install the included addon. API availability and custom-addon policies depend on your host.
  • Authenticated Connector: Configure HTTPS, OAuth, encrypted storage and approved Odoo hosts.
  • Company Configuration: Map unfamiliar completion, required fields and submit/approve actions.
  • Validate Before Production: Test the included Odoo runtime suite and one confirmed staging write.
Questions & Answers

Frequently asked questions

Connection requirements, custom modules and how changes reach Odoo.

Does this need an Odoo API key?

Live access uses your own Odoo API key, entered only in the deployed connector’s secure setup form. Never paste a key, password or cookie into ChatGPT. The illustrative examples on this website use fictional data and have no live connection.

Can it change records in my Odoo instance?

The v0.2.0 connector implements reads and writes for accessible work. Changes require an exact preview and confirmation, then Odoo permission checks and saved-result verification. Production use requires a configured deployment and staging validation.

Will it work with custom modules?

Administrators can map company-specific models, required fields, ownership and supported actions. Metadata is discovered on the actual instance. Unknown completion or approval behavior needs a verified mapping; the assistant does not guess a standard flow.

Which Odoo versions and deployments are supported?

Odoo 19 is the implementation target. Other versions need compatibility testing. The current package requires its included addon, an authenticated connector and appropriate API availability. Hosts that prohibit custom addons need a separate reviewed integration. See the setup guide for the current requirements.

Is the developer preview ready for production?

Local automated tests, browser checks and static addon checks passed. Live Odoo execution, real-provider OAuth and a ChatGPT-hosted connection still need staging validation. The package has no in-plugin billing, but Odoo, hosting and other service costs may apply.
