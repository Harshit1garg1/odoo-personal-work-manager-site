Current integration status

Live Odoo access is not available in the current release. The current ChatGPT plugin package contains workflow instructions; it does not host an Odoo connector, capture API credentials, or read or change an Odoo database.

A future connector is planned around the user's Odoo instance URL and a securely captured API key, using Odoo's supported external API where the particular deployment and subscription permit it. Never paste an API key or password into an ordinary ChatGPT message.

Free in the current release

The current release is free and has no paid features or in-plugin purchases. Future versions may introduce optional paid functionality; any such release will have updated pricing and applicable terms before it is offered.

Independent project

Odoo Personal Work Manager is developed independently by Harshit Garg. It is not an official Odoo product and is not affiliated with or endorsed by Odoo S.A. “Odoo” is used only to identify the software this project is designed to assist with.
