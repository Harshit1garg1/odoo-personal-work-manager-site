Privacy Policy

Effective date: 13 November 2026 · Applies to the current release

This policy describes the current Odoo Personal Work Manager website and ChatGPT plugin package. It must be revised before any future release adds a live Odoo connector, credential collection, analytics, or other backend data processing.

1. Who operates this project

Odoo Personal Work Manager is an independent project maintained by Harshit Garg (“the developer”). It is not an official Odoo product and is not affiliated with Odoo S.A.

2. What the current release does

The current ChatGPT plugin package provides workflow instructions for reviewing Odoo projects, tasks and timesheet information; planning workload; and safely preparing task updates. It does not include a remote MCP server, Odoo API client, credential form, or developer-operated database.

The developer does not receive Odoo API keys, passwords, Odoo records, ChatGPT prompts or uploaded files through a backend operated by this project in the current release. Do not send credentials to the developer through GitHub issues or other public channels.

3. Information processed by ChatGPT

When you use the plugin in ChatGPT, the prompts, files and other content you choose to submit are handled by OpenAI as part of the ChatGPT service. That processing is governed by OpenAI's applicable terms, privacy policy and account/workspace settings, not by this project. Review OpenAI's Privacy Policy and the OpenAI Privacy Portal for information and privacy controls.

Only provide Odoo information to ChatGPT when you are authorized to do so and your organization's policies permit it. Minimize or anonymize confidential, customer, employee and commercially sensitive information.

4. Website hosting and support issues

This informational website is hosted by GitHub Pages. GitHub may process technical information, including visitor IP addresses, for service operation and security as described in GitHub Pages documentation and the GitHub Privacy Statement. The website itself does not currently provide account registration, contact forms, advertising, or a developer-operated analytics service.

If you open a GitHub issue for support, the information you submit is handled by GitHub and is publicly visible in this public repository. Do not include secrets or personal/business data. See the Support page.

5. Cookies and analytics

The site does not intentionally set its own analytics or advertising cookies and does not embed third-party analytics scripts. GitHub's hosting platform and GitHub services may process technical data under their own policies.

6. Retention and deletion

The current project package does not collect or store Odoo credentials or Odoo records on developer-operated infrastructure. Website access logs, GitHub account data and support issue content are subject to GitHub's own retention and deletion practices. ChatGPT conversation data is subject to OpenAI's policies and the controls available for your account or workspace.

7. Future connector changes

A future release may allow users to configure an Odoo instance URL and API key through a separate secure connector. That functionality is not live in the current release. Before enabling it, this policy will be updated to explain the connector operator, data fields accessed, purpose, hosting locations, encryption, retention, deletion, subprocessors, access controls and contact route. Do not provide an API key to the current plugin.

8. Contact

For privacy questions about this project, contact the developer through the GitHub repository. Do not put sensitive information in a public issue. For ChatGPT data requests, use OpenAI's Privacy Portal; for GitHub data requests, use GitHub's own privacy channels.

9. Changes to this policy

This policy may be updated when the website or plugin changes. The effective date at the top will be revised when a new version is published.

Publication note: This policy describes the current workflow-only release. It is not a description of a future credential-handling connector, and it should be reviewed for legal suitability before public-directory submission.
